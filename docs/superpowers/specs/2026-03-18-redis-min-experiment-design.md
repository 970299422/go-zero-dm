# 设计：Redis 最小实验（Docker + redis-cli）

日期：2026-03-18
负责人：Dongm + Codex
状态：已批准

## 目标
在一个可随时删除的临时目录中完成最小 Redis 实验，以理解：
- 基本读写
- TTL 与过期行为
- 通过直接观察形成 Cache-Aside 直觉

## 范围
包含：
- 使用 Docker 在本机 6379 启动 Redis
- 用 redis-cli 跑一段最短命令链
- 观察 TTL 倒计时与过期 miss
- 写一句话总结

不包含：
- 应用接入
- 缓存一致性策略
- 多 key 设计、集群或持久化调优

## 方案备选
1. Docker + redis-cli 命令（推荐）
   - 反馈最快、最少代码
2. Docker + 最小 Go 脚本
   - 更贴近项目栈、略多准备
3. Docker + 最小 JS 脚本
   - 对前端熟悉，但与 Go 栈稍割裂

选择：方案 1

## 实验流程
1. 创建临时工作目录。
2. 用 Docker 启动 Redis（本机 6379）。
3. 运行以下命令链：
   - SET 一个 key
   - GET 读取
   - EXPIRE 设置 TTL
   - TTL 观察剩余时间
   - 等待过期后 GET 验证 miss
4. 记录一句话总结 Cache-Aside + 过期机制。

## 成功标准
- Redis 本地可达。
- TTL 正常递减并过期。
- 能用一句话说明流程，不看笔记也能讲清楚。

## 风险与应对
- Docker 不可用：改为本机安装 Redis 或先让用户启用 Docker。
- 6379 端口被占用：改用 6380 并同步更新命令。

## 交付物
- 一份命令清单与现象记录。
- 一句话总结。
